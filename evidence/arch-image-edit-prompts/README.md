# 증거 갤러리

템플릿을 실제 이미지 모델로 실행한 기록이다. 성공과 실패를 모두 남긴다. 모든 이미지는 가상 건물이며 실제 프로젝트가 아니다. 각 케이스는 1회 생성이며 보편적 승률을 뜻하지 않는다. 도구는 모두 ChatGPT 웹(2026-09-18), 기준 이미지 한 장에서 분기했다.

## 지금까지의 결론

1. **ChatGPT 웹 편집은 이미지 전체를 다시 그린다.** 잎·그림자·질감이 매번 미세하게 바뀌므로 픽셀 단위 보존은 성립하지 않는다. 판정은 윤곽·층수·요소 같은 구조 단위로 한다. 스크립트의 구조 지표(축소·블러 후 비교)가 이를 위해 있다.
2. **한 줄 프롬프트가 구조를 깨뜨린 사례는 두 쌍 중 하나도 없었다.** 재질 교체(01/03)와 대상 강조(06a/06b) 모두 매스·층수·카메라가 유지됐다. 이 도구에서 고정·금지 목록의 실질 효과는 변경 범위를 좁게 유지하고(01: 22.9% vs 27.7%) 요청하지 않은 톤 변화를 억제하는 정도다.
3. **"제외 부위" 문장이 효과가 있었던 것으로 보인다.** 케이스 01은 필로티 기둥이 함께 바뀌었고, 같은 건물 하부를 명시적으로 제외한 케이스 04는 번짐이 없었다. 두 케이스는 영역과 프롬프트가 달라 1회 비교로 인과를 단정할 수는 없다.
4. **영역 지정은 ±1층 정밀도.** 편집기 마크업 사각형은 "이 부근"으로 해석된다. 정확한 경계는 이미지 안의 선(발코니 슬래브 등)으로 지정해야 한다.
5. **깊이 방향 형상 서술은 실패한다.** "벽에서 바깥으로 기울어진 핀"은 입면 위의 사선 핀으로 그려졌다. 정면에 가까운 뷰에서는 깊이가 보이지 않으므로, 이 뷰에서 어떻게 보여야 하는지로 바꿔 써야 한다.
6. **정량 지시("채도 30% 감소")는 거의 반영되지 않는다.** 상대 표현이 나은지는 추가 시험 대상.
7. **편집 화면의 버전 썸네일로 원본에서 분기할 수 있다.** 재첨부 없이 편집 6건(실행 7회)을 같은 원본에서 시작했다.

각 폴더: `prompt.md`(입력 프롬프트와 조건), `result*.jpg`, `compare*/report.jpg`·`overlay.jpg`·`report.json`, `floors_*.jpg`, `verdict.md`(측정·관찰·판정·스킬 반영). 스크립트가 만드는 `diff.png`·`leak_outside_mask.png`는 재생성 가능해 저장소에서 제외했고, PNG 출력은 JPEG로 변환해 넣었다. `mask_preview.jpg`는 마스크 위치 확인용이다. 색 통계(벽돌색 비율, 채도)는 `skills/arch-image-edit-prompts/scripts/region_stats.py`로 재현한다. 판정 기준은 [references/preservation-checklist.md](../../skills/arch-image-edit-prompts/references/preservation-checklist.md).
