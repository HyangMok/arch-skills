# 보존 확인 목록

생성 **전**에 지킬 값을 적고, 생성 **후**에 같은 목록으로 대조한다. 적지 않은 것은 확인할 수 없다.

## 생성 전: 고정 값 기록

| 항목 | 기록 방법 | 예 |
|---|---|---|
| 카메라 | 건물 주요 모서리 2~3개와 지평선의 화면 내 위치 | 좌측 모서리 x≈18%, 지평선 y≈62% |
| 매스 윤곽 | 동 수, 각 동의 대략 폭·높이 비, 기울기 여부 | 판상형 3동, 남측 면 약 8° 기울어짐 |
| 층수 | 수평 분절선 수. 동별로 | 12 / 12 / 9 |
| 저층부 | 필로티 층수, 개방 여부 | 필로티 2개층, 서측 개방 |
| 개구부 | 커튼월·창호 위치와 폭 | 중앙 커튼월 폭 약 1/3 |
| 배경 | 주변 건물 수, 산 능선, 나무, 사람·차량 위치 | 좌측 저층 4채, 우측 가로수 3 |
| 글자 | 이미지 안 글자 원문 | 없음 / "…" |
| 변경 허용 영역 | 마스크 이미지 또는 말로 정의 | 남측 상부 입면만 |

이 표를 프롬프트의 고정 목록으로 그대로 옮긴다.

## 생성 후: 대조

1. **겹쳐 보기.** 원본과 결과를 50% 투명도로 겹친다. 모서리와 지평선이 어긋나면 시점 실패. `scripts/compare_edit.py`가 윤곽 겹침 PNG를 만든다.
2. **층수 세기.** 분절선을 동별로 다시 센다. 하나라도 다르면 실패.
3. **변경 영역 안팎.** 마스크가 있으면 스크립트의 안/밖 차이 비율을 본다. 밖의 차이 비율이 높으면 부분 편집 실패.
4. **금지 목록 훑기.** 새 소품·문구·장식이 생겼는지, 글자가 바뀌었는지.
5. **확대 검사.** 200% 이상 확대해 창호 선의 직선성, 벽돌 모듈의 일관성, 조경의 형태를 본다. 붓터치처럼 보이면 검토용 판정.
6. **판정 기록.** 통과 / 검토용 / 실패와 실패 항목을 한 줄로 남긴다.

## 스크립트

```bash
# 마스크 없이: 윤곽 겹침과 전체 차이 비율
python scripts/compare_edit.py original.png result.png --out compare/

# 마스크 있음: 흰색 영역이 변경 허용, 검정이 보존 영역
python scripts/compare_edit.py original.png result.png --mask allowed.png --out compare/

# 층수 어림: 동마다 창이 반복되는 세로 띠 하나를 픽셀 박스(x0 y0 x1 y1)로 지정. 필로티와 하늘은 제외
python scripts/count_floors.py result.png --strip 400 190 470 585 --strip 970 185 1030 625 --min-period 18 --out floors.png

# 영역 색 통계(벽돌색·유리색 픽셀 비율, 채도): 같은 원본의 결과들을 비교할 때
python scripts/region_stats.py --box curtain 800 160 940 600 original.png result.png
```

`count_floors.py`는 어두운 창 띠를 세는 방식이라 정면의 밝은 입면에서만 쓸 만하다. 기울어진 동, 어두운 재질로 바뀐 면, 야간 이미지에서는 1~2층 어긋난다(증거 갤러리에서 좌측 동을 일관되게 11로 계수했고 실제는 12). 최종 층수는 눈으로 센다.

용어 대응: 보고 이미지의 "구조 윤곽 일치" = `report.json`의 `structure_match_ratio` = 이 문서의 "윤곽 일치율".

출력:

- `report.png`: 원본, 결과, 검사 세 장을 나란히 놓은 한 장짜리 보고. 검사 패널에서 허용 영역 안 변경은 노란색, 밖 변경(누출)은 빨간색, 허용 경계는 초록 선. 아래에 비율과 확인 힌트. 사용자에게 보여 줄 때는 이 파일 하나면 된다.
- `overlay.png`: 결과 위에 원본 윤곽(빨강)과 결과 윤곽(청록)을 겹친 그림. 두 색이 어긋나면 시점 이동이나 매스 변형.
- `leak_outside_mask.png`: 결과 위에 누출 부분만 빨갛게 칠한 그림.
- `diff.png`, `report.json`: 픽셀 차이와 수치(전체·허용 안·허용 밖 변경 비율, 윤곽 일치율, 힌트).

비율은 절대 기준이 아니라 같은 원본에서 나온 결과들을 서로 비교하는 용도다. 힌트는 판정이 아니라 눈으로 볼 곳을 가리킨다.

`assets/example/`의 가상 도식 건물로 실행하면 의도한 재질 변경(노랑)과, 시험용으로 **일부러 심어 둔** 누출 두 곳(우측 동 층수 9→8, 좌측 동 옥상의 "SALE" 간판)이 빨갛게 표시된다. 실제 모델 결과는 `cases/`에 있다.

## 구조 단위와 픽셀 단위

ChatGPT 웹 편집처럼 이미지 전체를 다시 그리는 도구에서는 나무 잎, 그림자, 도로 질감이 매번 미세하게 바뀐다. 픽셀 단위로 재면 화면의 3~5%가 "누출"로 잡히지만 구조는 그대로다. 스크립트는 두 값을 모두 낸다.

- `changed_ratio_*` (기본): 256px로 축소하고 블러한 뒤 비교. 재질 교체, 추가 요소, 층수 변화처럼 면적이 있는 변경만 남는다. 실행 기록에서 재질 교체 1건의 마스크 밖 값은 0.2%였다.
- `*_fine`: 원본 해상도 픽셀 비교. 재렌더 노이즈를 포함하므로 같은 원본의 결과들 사이 비교에만 쓴다.
- `structure_match_ratio`: 축소·블러·팽창한 윤곽의 겹침. 재질 교체에서 87~89%, 시간대 교체에서 약 70%였다. 조명이 바뀌면 창 명암이 반전되어 낮아지므로 **유형 C에서는 이 값 대신 overlay.png의 건물 외곽선을 눈으로 본다.**

## 판정 기준 제안

- **통과**: 외곽선 일치(overlay), 층수 일치, 마스크 밖 구조 변경이 0.5% 미만이거나 같은 원본의 다른 결과보다 낮음, 금지 항목 없음.
- **검토용**: 위를 만족하지만 확대 시 표현이 뭉개짐. 협의 자료로는 쓰되 최종본 아님.
- **실패**: 시점·층수·역할 중 하나라도 어긋남. 다음 편집의 입력으로 쓰지 않는다.

## ChatGPT 웹에서 원본으로 되돌아가기

편집 화면 왼쪽의 버전 썸네일에서 첫 버전(원본)을 선택한 뒤 편집 지시를 입력하면, 이미지를 다시 첨부하지 않고도 원본에서 분기한 새 결과를 만들 수 있다. 여러 대안을 같은 원본에서 시험할 때 쓴다. 다운로드 버튼은 현재 선택된 버전을 내려받는다.
