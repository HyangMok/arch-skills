# 프롬프트 뼈대

여섯 구획으로 나눠 쓴다. 구획 제목은 모델이 아니라 작성자를 위한 것이므로 최종 프롬프트에서는 번호만 남기거나 빼도 된다. 순서는 바꾸지 않는다.

## 0. 역할 선언 (첨부가 둘 이상일 때 필수)

```text
이미지 1은 수정할 원본이다. 건물 디자인·재질·카메라 구도를 유지한다.
이미지 2는 분위기와 재질 표현만 참고한다. 형태나 구도는 가져오지 않는다.
이미지 3은 수정 영역을 표시한 주석이다. 표시 색은 실제 색이 아니라 설명 기호다.
```

## 1. 고정 (Scene, 무엇을 지키는가)

지켜야 할 것을 **이름을 붙여** 나열한다. "매스 유지"처럼 한 단어로 쓰면 모델은 대강 비슷한 매스를 만든다. 층수, 분절 수, 필로티 층수, 개구부 위치, 배경 요소를 세어서 적는다.

```text
지상 12층 판상형 매스 3개. 각 동의 수평 분절선 12개. 1층 필로티 2개층 높이.
중앙 커튼월 위치와 폭. 배경의 가로수·보행자·차량. 하늘의 구름 배치.
```

## 2. 변경 (이번에 바꿀 것)

한 프롬프트에 변경은 한 종류만 둔다. 재질과 시간대를 동시에 바꾸면 어느 쪽이 실패했는지 알 수 없다. 예외는 유형 B(캡처→렌더)처럼 변경이 본질적으로 묶여 있는 경우다. 그때는 변경 항목마다 경계를 이미지 안의 선으로 고정해 실패 지점을 나중에 분리할 수 있게 한다.

## 3. 금지

모델이 습관적으로 하는 것을 미리 막는다. 관찰된 습관은 [failure-diagnosis.md](failure-diagnosis.md) 참고.

```text
새 소품·간판·물방울·영문 장식을 추가하지 않는다. 매스를 수직으로 펴지 않는다.
층수를 바꾸지 않는다. 카메라를 이동하거나 회전하지 않는다. 이미지 안의 글자를 바꾸지 않는다.
```

## 4. 카메라

```text
원본과 동일한 카메라 위치·높이·초점거리. 건물 모서리와 지평선의 위치를 그대로 유지한다.
```

시점 유지가 목적인 작업에서는 이 구획을 고정 목록 바로 다음에 올려도 된다.

## 5. 조명·색

시간대와 광원 방향을 하나로 정한다. "황혼" 대신 "일몰 직후, 서쪽 하늘 주광, 실내 조명 켜짐"처럼 쓴다. 기존 렌더의 분위기를 따를 때는 "이미지 2와 같은 시간대와 색온도"라고 참조한다.

## 6. 재질·질감

재질은 **모듈 단위, 줄눈, 색 편차, 표면 상태**로 쓴다.

```text
적갈색 점토벽돌. 표준 벽돌 모듈, 밝은 회색 줄눈, 벽돌마다 미세한 색 편차. 무광.
과도하게 매끈하거나 나무결처럼 보이는 표현은 제거한다.
```

## 언어

이 문서의 템플릿은 읽기 쉽게 한국어로 적었다. 증거 갤러리의 실행 프롬프트는 모두 영어였고, 한국어 프롬프트로는 시험하지 않았다. 모델에 넣을 최종본은 영어로 쓰는 것을 기본으로 하고, 이미지 안에 남겨야 할 한국어 글자는 그대로 인용한다.

## 새 대화용 완결형

재생성이 누적되면 시점과 형태가 조금씩 어긋난다. 새 대화에서 다시 시작할 때는 이전 대화의 맥락을 전제하지 않는 **완결형** 프롬프트를 쓴다. 역할 선언부터 재질까지 한 덩어리로 붙일 수 있게 만든다.
