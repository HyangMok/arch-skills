# 작업 유형별 템플릿

꺾쇠 안을 채운다. 예시 문장은 가상 건물 기준이다. 모든 템플릿은 [prompt-skeleton.md](prompt-skeleton.md)의 고정·변경·금지 구조를 따른다.

## A. 재질·입면 교체

매스·시점·배경은 그대로, 외장만 바꿀 때.

```text
첨부 이미지의 건물 형태, 매스, 입면 구성, 창호 위치, 루버 간격, 주변 조경, 카메라 구도는 그대로 유지한다.
외장 <벽면 범위: 예 "3층 발코니 슬래브 선부터 옥상 파라펫까지">의 재질만 <목표 재질>로 바꾼다. 같은 건물의 <제외 부위: 필로티 기둥, 커튼월, 옥탑, 발코니 난간>은 현재 재질을 유지한다.
<목표 재질>은 <모듈 크기>, <줄눈 색>, <색 편차>, <표면 상태>로 표현한다.
현재의 <제거할 표현: 과도하게 매끈한 / 나무결 같은 / 균일한 단색> 표현은 제거한다.
새 요소를 추가하지 않는다. 층수와 개구부 위치를 바꾸지 않는다. 이미지 안의 글자는 유지한다.
```

참고 이미지가 있으면 첫 줄에 "이미지 2의 벽돌 톤과 줄눈 표현만 참고하고 형태는 가져오지 않는다"를 붙인다.

실행 기록([cases/01](../cases/01_A_material_swap/verdict.md)): 제외 부위를 쓰지 않았을 때 필로티 기둥이 함께 벽돌 톤으로 바뀌었다. 커튼월은 "stays glass"라고 명시해 유지됐다.

## B. 캡처를 렌더로

뷰포트 캡처(무채색 매스, 선 위주)를 참고 렌더의 분위기로 그릴 때. 입력에 재질·조명 정보가 없어 모델이 채워 넣을 것이 가장 많으므로 형태 보존이 가장 어려울 것으로 예상하는 유형이다. 증거 갤러리에는 아직 실행 기록이 없다.

이 유형은 재질·조명·주변이 한 번에 바뀌므로 "변경은 한 종류만" 규칙의 예외다. 대신 재질 경계를 이미지 안의 선으로 고정한다: "저층부는 <M>층 상부 슬래브 선까지 노출콘크리트, 그 위는 알루미늄 패널". 마스크가 없는 캡처→렌더 결과는 `compare_edit.py`의 구조 윤곽 일치율이 의미가 없다(선화와 렌더의 윤곽이 다르다). 겹침 이미지의 건물 외곽선과 층수 계수로 판정한다.

```text
이미지 1은 3D 뷰포트 캡처로, 건물의 형태·비율·카메라 각도의 기준이다. 이 형태와 각도를 그대로 유지한다.
이미지 2는 렌더링 분위기(시간대, 색온도, 주변 표현, 재질감)만 참고한다. 이미지 2의 건물 형태는 가져오지 않는다.
각 동의 층수는 이미지 1의 수평 분절선 수와 같다: <동별 층수>.
<필로티/저층부 높이 조건>.
재질: <수평 부위 재질>, <수직 부위 재질>. <살려야 할 디테일: 기둥 상부 틈, 프레임 돌출 등>.
주변은 <도심 저층 주거지 / 공원 / 산 능선>으로 채우되 대상 건물보다 채도를 낮춘다.
카메라를 이동하거나 화각을 바꾸지 않는다. 매스를 늘리거나 줄이지 않는다.
```

층수를 숫자로 적지 않으면 모델은 비율만 맞추고 층수를 바꾼다. 캡처에 분절선이 없으면 프롬프트를 쓰기 전에 사용자에게 층수를 확인한다.

## C. 배경·시간대 교체

```text
중앙의 건물은 형태·재질·창호·그림자 방향을 포함해 픽셀 수준으로 유지한다.
배경만 <목표: 저층 주거지 / 공원 / 야간 / 1시간 이른 오후>로 바꾼다.
광원 방향은 원본과 같게 유지하고, 시간대 변경에 따른 색온도만 조정한다.
사람·차량의 위치는 유지하고 조명 상태만 시간대에 맞춘다.
```

## D. 주석 이미지 국소 수정

빨간 선, 노란 박스 같은 표시가 있는 두 번째 이미지를 함께 줄 때.

```text
두 장의 이미지를 사용해 이미지 1을 수정한다.
이미지 1은 최종 렌더 원본이다. 이미지 2는 수정할 영역을 설명하기 위한 주석 이미지다.
이미지 2의 <색> 선은 실제 색을 적용하라는 뜻이 아니다. <색>은 <의미: 수정 영역 경계 / 첫 번째 프레임 타입 / 두 번째 프레임 타입>을 나타낸다.
표시된 영역 안에서만 <변경 내용>을 적용한다. 영역 밖의 모든 요소는 원본과 동일하게 유지한다.
```

주석 색이 두 가지 이상이면 색마다 의미를 한 줄씩 따로 쓴다.

파일을 첨부할 수 없으면 ChatGPT 편집 화면의 마크업 도구로 원본 위에 직접 사각형을 그리고 "The red rectangle I drew marks the edit region only… the rectangle itself must not appear in the result"로 시작한다. 실행 기록([cases/04](../cases/04_D_annotation_region/verdict.md)): 사각형은 결과에 남지 않았고 재질은 영역 안에만 적용됐으나 경계는 ±1층 오차. 정확한 경계는 "3층 아래 발코니 슬래브 선에서 끝난다"처럼 이미지 안의 선으로 쓴다.

## E. 비율·구도 보정

```text
이미지 1의 건물 디자인, 재질감, 렌더링 품질은 유지한다.
이미지 2의 건물 비율과 배경 구도에 맞춰 이미지 1의 건물을 보정한다.
구체적으로 건물의 <가로 폭을 줄여 / 세로 높이를 낮춰> 화면 안에서 <더 컴팩트하게 / 중앙에> 배치하고, 이미지 2와 같은 배경 여백과 주변 건물 관계를 만든다.
층수와 개구부 수는 이미지 1을 유지한다. 새 디자인 요소를 추가하지 않는다.
```

이 유형은 "디자인 생성"이 아니라 "보정"임을 첫 줄에 밝힌다.

## F. 반복 모듈 서술

프레임 기울기, 루버 간격처럼 모델이 계속 틀리는 반복 요소. 그림으로 보여도 안 되면 **왼쪽 첫 단위부터 순서대로 말로** 쓴다.

```text
수직 프레임은 다음 모듈이 반복된다. 왼쪽 첫 프레임부터:
1. 위쪽이 벽면에서 <돌출량> 튀어나오고 아래쪽은 벽면에 붙는다. 옆에서 보면 삼각형.
2. <간격> 띄운 다음 프레임은 반대로 아래쪽이 튀어나오고 위쪽이 벽면에 붙는다. 역삼각형.
3. 1과 2가 <총 개수>회 반복된다.
모든 프레임의 색은 <색>, 두께는 <두께>로 동일하다.
루버는 <간격>마다 하나, 깊이 <깊이>, 위아래 수평 부재가 받치는 형식. 벽면 하나를 연속된 한 면으로 보고 끊김 없이 배치한다.
```

L자형이나 꺾인 면은 "두 면을 따로 잡지 말고 하나의 연속 면으로" 명시한다. 셀 단위 패턴은 "끝단에 잘린 셀이 생기지 않게 간격을 등분"이라고 쓴다.

**깊이 방향 형상은 이 뷰에서 보이는 모습으로 쓴다.** 실행 기록([cases/05](../cases/05_F_repeat_module/verdict.md)): "벽에서 바깥으로 기울어진 핀, 옆에서 보면 삼각형"은 입면 위의 사선 핀(V·X자)으로 그려졌다. 반복·간격·끝단 규칙은 지켜졌다. 깊이 변화가 목적이면 다음처럼 바꾼다.

```text
In this view every fin reads as a straight VERTICAL line; fins never cross each other and never appear diagonal on the facade.
The alternation is only in depth: fin 1 casts a wider shadow at the top, fin 2 at the bottom.
```

## G. 대상 강조 (조감도·투시도)

```text
대상 단지 <위치 설명>은 밝고 선명하게, 주변 시가지는 채도를 낮추고 약간 흐리게 처리해 대상이 먼저 읽히게 한다.
대상 단지의 매스 형태, 동 수 <N개>, 층수 <분절선 기준>, 동 사이 통경축 폭은 원본을 유지한다. 통경축을 임의로 넓히지 않는다.
전면의 주변 건물은 대상 건물보다 작게 표현한다. 뒷배경은 <산 능선 / 원경 시가지>.
동별 디자인은 <참고 이미지>의 언어를 따르되 매스 규모는 바꾸지 않는다.
```

## H. 새 대화용 완결형 조립

위 템플릿 중 하나를 골라 역할 선언 → 고정 → 변경 → 금지 → 카메라 → 조명 → 재질 순으로 한 덩어리로 붙인다. 이전 대화를 전제하는 표현("아까처럼", "이전 버전에서")을 모두 제거한다.
