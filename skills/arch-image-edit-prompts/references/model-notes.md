# 모델 관찰 노트

gpt-image 계열을 같은 프롬프트로 비교한 사례 관찰이다. 조건별 1회 생성을 본 것이므로 보편적 승률이나 향상률을 뜻하지 않는다. 공식 문서 주장과 사용자 관찰을 구분해 적는다.

## 공식 문서에서 확인한 것 (2026-09 기준)

| 항목 | 내용 | 출처 |
|---|---|---|
| 모델 | gpt-image-2와 gpt-image-2.5 계열이 API에서 지정 가능 | developers.openai.com/api/docs/models |
| 권장 용도 | 2.5는 편집 정밀도가 중요한 작업에 권장. 완벽한 보존을 보장하지는 않음 | 모델 페이지 |
| 품질 옵션 | 2.5에 xhigh, max 추가. 같은 이름의 high가 같은 계산량을 뜻하지는 않음 | guides/image-generation#size-and-quality-options |
| 투명 배경 | PNG·WebP 투명 배경 출력 지원. 유리 같은 재질의 시각적 투과와 파일의 알파는 별개 | 같은 문서 |
| 크기 | 사용자 지정 크기는 2.0과 2.5 모두 지원 | guides/image-generation |
| 한계 | 한국어 정확도, 반복 편집 열화 등의 개선은 공식 보장이 아니라 사용자 검증 대상 | guides/image-generation#limitations |
| 가격 | 토큰 요율은 같고, 이미지당 비용은 응답 usage에 따라 다름 | pricing#image-generation |

문서 주소와 내용은 바뀔 수 있으므로 인용 전에 다시 연다. 2026-09-21에 image-generation 가이드 페이지를 다시 열어 모델명(gpt-image-2.5-sunburst, flare), 품질 옵션(low·medium·high·xhigh·max·auto), 투명 배경(background: transparent, PNG·WebP)을 확인했다.

## 사용자 관찰 (이미지 필드노트 실험 중 건축 편집에 시사점이 있는 것)

아래는 문서·음식·타이포 등 20건의 비교 실험에서 나온 관찰이다. 건축 이미지가 아니지만 편집 행동의 경향으로 참고한다.

- **편집 정밀도 vs 추가 요소.** 2.5는 지정한 차트 종류·조판·편집 지시를 더 잘 따랐지만, 요청하지 않은 소품·아이콘·영문 장식·물방울을 더 자주 덧붙였다. 정밀도가 높은 모델에서 금지 목록을 더 길게 쓰는 이유다.
- **반복 편집 드리프트.** 같은 원본을 3회 연속 편집했을 때 2.0은 거친 미세 패턴이 늘고 2.5는 표면이 지나치게 매끈해졌다. "덜 자글자글하다"와 "원본 질감을 보존했다"는 다른 것이다.
- **가격·글자 한 곳만 수정.** 지시한 곳의 수정은 양쪽 모두 성공했지만 주변 재질 디테일도 함께 변했다. 픽셀 보존이 필요하면 생성 후 대조가 필수다.
- **텍스트가 정확해도 가리키는 대상이 틀릴 수 있다.** 라벨 20개를 다 맞게 써도 안내선의 끝점이 잘못 연결된 사례가 있었다. 건축에서는 동번호가 맞아도 위치가 틀린 경우에 해당한다.
- **참조 이미지의 역할 혼동.** 모델과 무관하게, 역할을 첫 줄에 선언하지 않으면 뷰 참조와 디자인 참조가 뒤바뀌었다.
- **내장 생성 도구.** 코딩 에이전트에 내장된 이미지 생성은 출력 해상도와 모델 옵션을 직접 고르기 어렵다. 고해상도나 특정 모델이 필요하면 API 경로를 별도로 확인한다.

## ChatGPT 웹 편집에서 확인한 것 (2026-09, 저장소 evidence/ 참조)

- 편집은 부분 인페인팅이 아니라 **전체 재렌더**다. 바꾸지 말라고 한 영역도 잎·그림자·질감이 미세하게 달라진다. 건물 외곽선과 층수는 유지됐다.
- 단순 재질 교체는 한 줄 프롬프트로도 커튼월·다른 동·층수가 유지됐다. 구조 프롬프트는 변경 범위를 더 좁게 유지했다.
- 편집 화면의 버전 썸네일로 원본을 다시 선택해 분기할 수 있다.
- 생성 프롬프트의 각도·위치 수치("8도 기울기", "정면 가운데")는 대략적 힌트로만 작동했고, 층수 수치는 대체로 지켜졌다.

## 도구별 프롬프트 붙이기

- **ChatGPT 웹**: 이미지를 먼저 올리고 프롬프트를 붙인다. 이미지 순서가 역할 선언의 번호와 같아야 한다. 재생성이 누적되면 새 대화.
- **API**: 편집은 원본과 마스크를 입력으로 준다. 마스크의 흰색이 변경 허용 영역이다. `preservation-checklist.md`의 마스크와 같은 파일을 쓸 수 있다.
- **코딩 에이전트 내장 생성**: 프롬프트를 파일로 저장해 두고 재사용한다. 같은 프롬프트를 두 도구에 넣어 결과를 비교하면 도구 차이가 드러난다.
