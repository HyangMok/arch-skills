# 판정: 케이스 00 기준 이미지

**채택.** 실제 값은 `preservation.md`.

## 관찰

- 프롬프트의 수치 사양 중 층수는 대체로 지켜졌고(12 / 12 / 8~9), 위치 사양(커튼월 "가운데")과 각도 사양("8도")은 지켜지지 않았다. 생성 단계에서 각도와 위치는 대략적인 힌트로만 작동한다.
- "No text, signs or logos"는 지켜졌다.
- 카메라 높이 지시("slightly above eye level")보다 높은 준조감으로 나왔다. 생성 시 카메라 높이는 자주 과장된다.
- 1회 생성으로 채택. 재생성하지 않은 이유: 편집 케이스의 원본으로는 "특정 값이 무엇이든 고정되어 있는 것"이 중요하고, 큰 기울기와 비대칭 커튼월은 오히려 보존 실패를 드러내기 좋다.

## 이 케이스가 스킬에 주는 교훈

- 생성 프롬프트의 각도·위치 수치는 결과를 보고 다시 측정해 기록해야 한다. 이후 편집 프롬프트는 프롬프트의 사양이 아니라 **실제 이미지의 값**을 고정 목록으로 써야 한다.
