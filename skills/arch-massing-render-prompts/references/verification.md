# 생성 후 대조

`scripts/check_render.py`로 겹침·확대 이미지를 만든 뒤 아래 표를 채운다. 판정은 구조 단위(모서리·층수·요소)로 한다. 잎·그림자·질감은 매번 다르므로 픽셀 차이는 보지 않는다.

```bash
python scripts/check_render.py capture.png render.png --out check/ \
  --edges capture_edges.png \
  --box A x0 y0 x1 y1 --box D x0 y0 x1 y1 \
  --strip A x0 y0 x1 y1 --strip D x0 y0 x1 y1
```

`--edges`가 없으면 캡처에서 윤곽을 추출한다. `--box`는 겹침 확대 영역, `--strip`은 층수를 셀 입면 기둥(폭 100px 안팎, 지붕에서 지반까지)이다.

## 보는 법

- **카메라**: `overlay.jpg`에서 동 모서리·지붕선·대지 경계가 빨간 선 위에 있으면 통과. 한 동만 어긋나면 카메라가 아니라 그 동의 형상 문제다.
- **층수**: `strip_*.jpg`에서 왼쪽(캡처)의 층선 수와 오른쪽(렌더)의 창 띠 수를 눈으로 센다. 지상층은 층고가 다르게 그려지므로 따로 센다. ±1은 뷰 각도에 따른 오차 범위로 본다.
- **높이 방향 진단**: 지붕선이 빨간 윤곽 위로 나가면 층수 초과(타워에서 관찰), 지붕은 맞는데 창 띠 간격이 층선보다 넓으면 층수 부족(판상형에서 관찰).
- **기계적 층수 세기**: 밝기 주기로 어림하는 스크립트는 사선 뷰의 캡처 자체에서도 어긋났다. 정면에 가까운 입면이 아니면 쓰지 않는다.

## 판정 수준

- **통과**: 모든 행 통과. 그대로 쓴다.
- **부분 통과**: 카메라·배치는 맞고 층수 ±1~2 또는 한 동 표현 어긋남. 분위기·초안 용도로만 쓰고 층수가 걸린 자료에는 캡처를 고쳐 재생성.
- **실패**: 카메라 이동, 동 추가·삭제, 매스 변형. 새 대화에서 캡처를 다시 첨부해 처음부터.
