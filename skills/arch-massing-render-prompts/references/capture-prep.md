# 캡처 준비 점검표

이미지 모델은 캡처에 그려진 것을 텍스트보다 우선한다. 렌더에서 지켜야 할 것은 먼저 캡처에 그린다.

## 반드시

| 항목 | 이유 |
|---|---|
| 면은 무채색(밝은 회색), 윤곽선은 검고 선명하게 | 모서리 위치가 렌더의 모서리 위치가 된다 |
| **층마다 가로 선 하나** | 층수를 읽는 유일한 단서. 선이 없으면 모델이 임의로 나눈다 |
| 필로티는 개방 높이만큼 기둥 선을 그린다 | 기둥 선이 있으면 필로티가 유지됐다(5/5회) |
| **한 동은 한 덩어리로** | 별개 박스를 붙여 내부 모서리선이 남으면 프롬프트에 써도 두 동으로 그려진다(4/4회). 한 덩어리로 그리면 한 동으로 나왔다(1/1회) |
| 대지 경계선, 도로는 회색 띠로 | 대지 밖 시가지·도로 배치가 이 선을 따른다 |
| 배경은 단색으로 비운다 | 주변은 텍스트로 지정한다. 캡처에 다른 건물이 있으면 그대로 그려진다 |
| 비율 3:2 또는 16:9, 긴 변 1536px 이상 | 생성 결과 크기와 맞추면 윤곽 겹침이 바로 된다 |

## 정답표를 같이 만든다

캡처를 저장할 때 동별로 적는다. 생성 후 대조의 기준이다.

```
A  전면 판상형   15층
B  우측 판상형   12층, 필로티 2층(기둥)
C  좌측 L자형    10층, 두 날개 한 동
D  후방 타워     20층
카메라: 남서쪽 상공, 대지 중심을 봄
```

## 층수가 걸린 자료라면

실행 기록에서 층수는 어느 조건에서도 정확히 맞지 않았다(판상형 −1~2, 타워 +1~6). 캡처 쪽 대책을 한 번 시험한 결과다. 쓰면 결과를 대조표에 남기고 이 표를 갱신한다.

| 대책 | 시험 결과 |
|---|---|
| 층 분절선 3px 진회색 + 동별 층수 라벨("15F") + 프롬프트 "labels are instructions, not objects, must not appear" + "one window row per drawn line, no more, no fewer" | 1회. 라벨은 글자로 남지 않았다. 판상형 층수는 v1 결과보다 1 정도 나았지만 ±1 오차 안이라 효과 불명. 부작용은 없었다 |
| 타워 지붕에 옥탑 박스 + "parapet at the top drawn line" | 1회. 옥탑은 기계실로 그려졌으나 주 지붕은 여전히 +2. 효과 없음 |
| 구조 프롬프트의 동별 층수 문장 | 3회. 층수를 맞추지는 못하나 타워 과대를 +1~3으로 줄임(한 줄은 +4~6) |

미시험 후보: 타워 옆에 같은 높이의 기준 매스를 두는 것, 타워가 앞 동에 가리지 않는 카메라, 라벨만 / 굵은 선만 넣어 효과 분리.

## 하지 않는다

- 컬러 재질이 붙은 캡처. 재질은 텍스트로 정하고 캡처는 형상만 준다.
- 격자 바닥 위에 치수선·문자가 남은 캡처. 글자는 렌더에 글자로 남을 수 있다.
- 여러 시점을 한 장에 합친 캡처.
