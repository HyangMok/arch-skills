# 어긋났을 때

증상별 원인과 대책. "관찰"은 실행 기록에서 본 것, "미시험"은 아직 확인하지 않은 대책이다.

| 증상 | 원인으로 보이는 것 | 대책 |
|---|---|---|
| 판상형 층수가 1~2층 적다. 지붕 높이는 맞다 | 창 띠 한 칸을 캡처 층선보다 크게 그림 (관찰 5/5회, −1~2) | 굵은 층선·층수 라벨·"one window row per drawn line" 문장을 넣은 1회는 ±1 안. 효과 불명. 층수가 걸리면 재생성 후 다시 세고 ±1~2 자료로 취급 |
| 타워가 윤곽보다 높다. 층 간격은 비슷하다 | 위로 연장 (관찰 5/5회). 구조 프롬프트 +1~3, 한 줄 +4~6 | 구조 프롬프트의 동별 층수 문장은 과대를 줄인다(3회). 옥탑 박스는 효과 없음(1회). 후경 타워는 앞 동에 가려 기준선이 없으므로 더 심하다. 미시험: 기준 매스, 카메라 변경 |
| L자·ㄷ자 한 동이 두 동처럼 보인다 | 캡처에서 별개 박스를 붙여 내부 모서리선이 남음 (관찰 4/4회). "두 날개는 한 동" 문장은 이기지 못함 | **캡처에서 한 덩어리로 합쳐 내부 선을 지운다 (1/1회 성공)** |
| 지시하지 않은 차량·횡단보도, 주변이 흰 블록 | 한 줄 프롬프트의 모델 기본값 (새 대화 1회 관찰) | 금지 목록과 주변 서술을 쓴다. 흰 블록 주변이 필요하면 의도적으로 요청(미시험) |
| 시점이 옮겨졌다 | 캡처가 아니라 첨부 이미지를 참고로만 해석 | 첫 문장에 "geometric reference, produce exactly this scene"을 넣고 새 대화에서 재첨부. 같은 대화에서 반복 재생성하지 않는다 |
| 대지 안에 차량·사람·간판이 있다 | 금지 목록 없음 (한 줄 프롬프트에서 예상) | 금지 목록을 쓴다. 이미 있는 렌더라면 `arch-image-edit-prompts` 유형 D로 국소 편집 |
| 주변에 요청하지 않은 고층이 섰다 | 주변 서술 없음 → 모델 기본값 | "Beyond the site: low-rise city fabric" 등으로 주변 높이를 지정 |
| 재질·조명이 이전 결과와 비슷하다 | 같은 대화의 이전 프롬프트가 문맥으로 남음 (관찰) | 대조군이나 다른 안은 새 대화에서 |
| 렌더 크기가 캡처와 다르다 | 도구의 출력 크기 | `check_render.py`가 캡처 크기로 맞춘다. 비율이 다르면 카메라 판정 불가 → 캡처 비율을 도구 출력 비율에 맞춰 다시 찍는다 |

## 반복 원칙

- 형상·층수 문제는 프롬프트가 아니라 **캡처를 고친다**.
- 재질·조명·주변·금지 문제는 **프롬프트를 고친다**.
- 고친 뒤에는 **새 대화**에서 캡처를 다시 첨부하고 완결형 프롬프트로 시작한다.
- 결과와 대조표를 남긴다. 미시험 대책이 통했는지 실패했는지가 다음 사람에게 가장 유용한 정보다.
